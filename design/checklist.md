# Checklist de revisión

Para usar **antes de entregar** cualquier pieza (marca, web, post, video,
packaging). Si algo da "no", se corrige antes de mandarlo.

## Antes de arrancar (brief)

- [ ] ¿Cuál es **el porqué real** detrás de la marca o la pieza?
- [ ] ¿**Para quién** es? (Si es para todos, es para nadie.)
- [ ] ¿Qué **emoción** tiene que generar? (Una sola: calma, intimidad,
      orgullo, adrenalina, nostalgia…)
- [ ] ¿Cuál es **la tensión**? (viejo/nuevo, calma/caos, tradición/rebeldía,
      orgánico/tech…)
- [ ] ¿**Dónde va a vivir**? (celular 9:16, web, calle, packaging, pantalla
      grande)
- [ ] ¿Qué tiene de **local / cultural** para tomar?
- [ ] Refes: ¿miré cómo lo hacen **los mejores** en ese rubro o formato?
- [ ] Assets: ¿**pedí** los efectos, fuentes y texturas en vez de perder tiempo
      buscándolos?

## Filtro final (las 10 leyes)

Puntuá de 1 a 5. Menos de 3 en cualquiera → volver.

| # | Pregunta | 1–5 |
|---|----------|-----|
| 1 | ¿Puedo explicar por qué existe **cada** elemento? | |
| 2 | ¿Saqué todo lo que sobraba? ¿Hay aire? | |
| 3 | ¿Hay **una** tensión o ruptura clara sobre una base ordenada? | |
| 4 | ¿Se siente la emoción **antes** de leer el texto? | |
| 5 | ¿Se nota una mano humana (textura, trazo, imperfección)? | |
| 6 | ¿Tiene profundidad: planos, sombras, relieve? | |
| 7 | ¿Son 2–3 colores con rol y un solo acento? ¿El texto se lee? | |
| 8 | ¿Tiene raíz? ¿Se nota de dónde viene? | |
| 9 | ¿Lo probé en su contexto real (mockup)? | |
| 10 | ¿Esto lo habría propuesto un diseñador promedio? | |

### La pregunta que manda

> **Revisá tus propuestas. Eliminá todo lo que un diseñador promedio también
> hubiera propuesto. ¿Qué queda?**

## Chequeos rápidos de composición

- [ ] Horizonte arriba o abajo, **no al medio**.
- [ ] Las miradas del sujeto apuntan hacia donde quiero llevar el ojo.
- [ ] Lo principal es claramente lo principal (primer plano que enmarca,
      máscara, contraste).
- [ ] Hay espacio negativo con intención.
- [ ] Las imágenes tienen sombra o contexto: no flotan "vacías".

## Para presentarle al cliente

- [ ] Mostrar **territorios de estilo** (2–4 direcciones distintas, cada una
      con nombre, refes, paleta y tipografía) para que el cliente conozca todas
      las opciones.
- [ ] Explicar cada decisión desde la emoción, con este formato:
      > **"No [lo obvio]. En cambio, [la decisión]. Porque [la emoción que
      > genera]."**
      > *Ej.: "Nada de veterinarios con guardapolvo. En cambio, momentos
      > felices y cotidianos de los dueños con sus mascotas. Porque las
      > imágenes generan emoción, y la conexión emocional vende."*
- [ ] Mostrar la pieza **en su lugar real** (mockup), no sola sobre blanco.
