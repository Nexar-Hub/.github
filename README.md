# .github

Default community health files for the Nexar-Hub organization.

- [`.github/pull_request_template.md`](.github/pull_request_template.md): default PR template.
- [`.github/ISSUE_TEMPLATE/task.yml`](.github/ISSUE_TEMPLATE/task.yml): scoped work request.

[`spread/`](spread/) holds Spread's decision bible, business context and tools. Spread is
independent from Nexar; the folder lives here temporarily and applies to Spread only.
