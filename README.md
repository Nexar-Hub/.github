# .github

Default community health files for the Nexar-Hub organization. Any repository in the
organization that has no file of its own in the same place uses these.

| File | Used as |
|------|---------|
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default body for new pull requests |
| [`.github/ISSUE_TEMPLATE/task.yml`](.github/ISSUE_TEMPLATE/task.yml) | "Task / work request" issue form |

These defaults only apply while this repository stays public. A repository that adds its own
`.github/ISSUE_TEMPLATE/` folder or PR template stops inheriting the matching default.
