## Decision architecture

Only for changes to user-facing copy, web, outbound, ads, pricing or proposals. Otherwise write N/A.
Framework: the Spread bible (`spread/bible/PLAYBOOK.md`).

- Reference point: where does the buyer think they stand today, and are we moving it on purpose?
- Lever(s) applied: separate gains / bundle costs / status quo as a loss / loss framing / large improbable prize / none
- Hypothesis and metric: what should move, and how will we know?

- [ ] No internal jargon in client-facing copy (signals, agents, decision architecture, Prospect Theory)
- [ ] Any loss we name is real and backed by the prospect's own data or a cited source
- [ ] No invented results, testimonials, metrics, case studies or clients
- [ ] Prices are shown as one total; guarantees and odds are stated honestly
- [ ] `python3 spread/tools/copy_audit.py` was run on the changed copy
