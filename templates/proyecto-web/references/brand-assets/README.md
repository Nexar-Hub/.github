# Carpeta para brand assets del cliente

Subí acá todo lo que es identidad oficial del cliente:

## Mínimo necesario

- `logo.svg` — Logo en SVG (preferido)
- `logo.png` — Logo en PNG (fallback)
- `logo-white.svg` — Versión blanca para fondos oscuros (si existe)
- `colors.png` o `colors.md` — Paleta de colores oficial

## Si el cliente tiene

- `brand-manual.pdf` — Manual de marca completo
- `fonts/` — Carpeta con archivos de fuentes (.woff2)
- `imagenes/` — Fotos del cliente, equipo, producto, locales

## Si NO tiene

Avisar al cliente que necesita conseguir lo básico:
- Logo en buena calidad (idealmente SVG)
- Decisión clara sobre paleta y tipografía

Sin esto, el sitio queda visualmente débil y la culpa es del proyecto, no del cliente.
