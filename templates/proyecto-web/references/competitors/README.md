# Carpeta para capturas de competencia

Subí capturas de sitios de competidores directos del cliente.

¿Para qué sirve?
- Identificar qué hace todo el mundo igual (para diferenciarse)
- Ver el estado del mercado en ese rubro
- Encontrar oportunidades visuales que la competencia no aprovecha

Idealmente: 2-5 competidores principales del cliente.
