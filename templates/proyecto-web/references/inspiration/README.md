# Carpeta para imágenes de inspiración

Subí acá entre 3-10 capturas o referencias de sitios que le gustan al cliente.

Idealmente:
- Capturas full-page de sitios que le gustan
- Referencias específicas de secciones (heros, footers, etc.)
- Estilos visuales que le atraen

Formatos aceptados: PNG, JPG, WebP

Claude Code va a leer estas imágenes al iniciar el proyecto para alinear el output visual.
